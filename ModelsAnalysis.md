# Supervised algo:

## Regression algorithms
### Linear REg:
linear relationship between input and target. target values are continuous
### Decision Tree Reg:
Nonlinear numerical predictions and rule-based relationships -> more focusedon decision rules
### Random Forest:
More robust nonlinear predictions -> A single tree is unstable or overfits.
### Support Vector Regression:
Complex nonlinear numerical predictions -> The dataset is not extremely large.
### KNN:
Predicting values based on similar observations

## Classification algorithms
### Logistic Reg:
Binary and multiclass classification -> linear realtionship
### Decision Tree Classifier	
Rule-based classification
### Random Forest Classifier	
General-purpose classification
### SVC	Classification 
with linear or nonlinear boundaries
### KNN Classifier	
Classification based on similar observations

# Unsupervised algo:

### K-Means Clustering
Divide observations into K groups based on similarity.
### KNN for anomaly detection
Identify observations that are unusually far from their nearest neighbors.
### Principal Component Analysis (PCA)
Reduce the number of features while retaining as much variance as possible.
### Isolation Forest
Isolates unusual observations using random partitions
