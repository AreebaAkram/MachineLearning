Multicollinearity:  happens when two or more independent (predictor) variables in a regression model are strongly correlated with each other.
they may contain overlapping information. It can make Logistic Regression coefficients unstable and harder to interpret.
Corelaion matrix is used to detect it. 
Look at pairwise correlations between predictors; values above 0.7 to 0.9 suggest strong collinearity

## DECISION TREE
-> Information gain will used to select features. how useful a feature is for splitting data into groups
Information gain is biased towards choosing attributes with a large number of unique values. Information Gain measures how much uncertainty is reduced after splitting a node.

-> Entropy : measure of impurity in a dataset. level of uncertainity -> total amount of missing information in a system
1. first calculate entropy of each attribute' class, then calculate information gain for each attribute. select attribute with highest information gain, that node becomes parent now, select accordingly for all next features
Entropy also measures how mixed the classes are

-> Gini Index: choose attribute that produces less impurity in the dataset. 0 means no impurity, all values belong to single class. 

Criterion	What it measures
Gini:	Impurity
Entropy:	Uncertainty
Information Gain:	Reduction in entropy

as the models slowly moves to certainity / clarity after selecting each node

## Random Forest:
each tree uses diff columns and rows of data to make predictions. 
-> reduces overfitting as each tree learns diff patterns

-> Ensemble learning: combines multiple individual models (called "base learners") into a single, unified model to produce better predictions
the models are homogenous in case of random forest

-> Bootstrap Sampling (selecting random rows): no of rows in orignal dataset and bootstrap sample size is equal so that one row can be selected multiple times and one of the rows can't be selected at all

no of tree = no of bootstrap samples. 
-> Random Feature Selection: The random feature selection happens at each node where the tree considers a split, not just once for the entire tree.

-> min_samples_split : no of rows present for that one specific parent node
-> min samples leaf: no of row for tha one specfic category of the feature

    min_samples_split=10,
    min_samples_leaf=5
Parent must have at least 10 rows to be considered for splitting.
Each resulting child must have at least 5 rows.
